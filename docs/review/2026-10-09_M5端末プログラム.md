## 3. 注意が必要な処理

### データを消す処理

| どこ | 何が消えるか | 守り |
|---|---|---|
| `applyAck()` | 端末に保存した歩数の記録（ACK で届いた時刻まで） | PC がサーバーに保存できたときだけ ACK が来る。「その接続で送った最後の時刻」より先は消さない |
| `appendRecord()` | 記録が 432 件を超えたときの一番古い記録 | 捨てた件数をボタンBの画面に出す |
| `loadState()` | 前に起動したときの「時計が合う前」の記録 | 本当の時刻に直せないため。シリアルに件数を出す |
| `saveState()` | 本体の保存領域（NVS）の `recs` | 記録が0件になったときだけ消す（0バイトは書けないため） |

### 外部との通信

- **BLE だけ**。Wi-Fi は使わない。接続してきた相手（PC）に記録を送る。
- **ペアリングなし**で接続できる。近くの人が同じ手順で接続すると、記録を読める・ACK で消せる（試作のため。制限として README に書いた）。

### 個人情報

- 端末に入るのは端末ID・時刻・歩数だけ。名前は入らない。

### 画像

- 使っていない（画面は文字と数字だけ。フォントは M5GFX に入っているもの）。

## 4. 仮で決めたこと（確認が必要）

| 点 | 仮の決め方 | 確認する相手 |
|---|---|---|
| 歩数の検出 | 揺れの山を数える。しきい値 0.12g、4歩続いてから数える | 実際に付けて100歩テスト（README の手順） |
| 記録の区切り | 10分ごと。歩いていない時間帯は記録しない | チーム |
| 画面 | ボタンAで今日の歩数、ボタンBで端末の情報、15秒で消える | チーム・施設（高齢者が見やすいか） |
| 電池 | 工夫はまだ（CPU を 80MHz に下げ、画面を消すだけ） | 実機で電池の減り方を測ってから |
| ボード・ライブラリの版 | ESP32 コア 3.x、M5Unified（M5StickS3 対応版）、NimBLE-Arduino 2.x | 端末担当（実際に入れてコンパイル） |

### 追記（2026-10-14）: コンパイルの確認

- 依頼者が Arduino IDE にボード定義（M5Stack 3.3.9）と M5Unified 0.2.19・M5GFX 0.2.26 を入れたので、Claude が足りなかった **NimBLE-Arduino 2.5.0** を入れた。
  Arduino のライブラリのサーバーにこの PC からつながらなかったため、**公式の GitHub（h2zero/NimBLE-Arduino）の 2.5.0 の zip** を落として `ドキュメント\Arduino\libraries\NimBLE-Arduino` に置いた（SHA256: 3FB34DB172D6E95057DF170E1B963702A44B8EF673B5C3923226C86409CB0C17）。
- `arduino-cli compile --fqbn m5stack:esp32:m5stack_sticks3 --warnings all` で**コンパイル成功**（フラッシュ 35%、RAM 12%）。
- 今回のプログラムの警告は1つだけで、NimBLE 2.5 では `NimBLEService::start()` がいらない（何もしない）というもの。その1行を消し、**警告0** になった。ほかの警告はボード定義（`pins_arduino.h`）の側のもの。
- 書き込みと実機の確認はまだ。
