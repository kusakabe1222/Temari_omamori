## 2. 動かし方

README の「段階5: LINE（本人用）」。LINE なしで試すときは、`.env` に `LINE_CHANNEL_SECRET`（試し用の文字列）と `LINE_DRY_RUN=1` を入れて:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.bot_main:app --port 8001
.\.venv\Scripts\python.exe scripts\fake_line.py "登録 123456"
.\.venv\Scripts\python.exe scripts\fake_line.py 今日
```

## 3. 注意が必要な処理

### インターネットに出す部分（いちばん大事）

- トンネル（Cloudflare Tunnel か ngrok）で、**LINE の入口（8001）だけ**をインターネットに出す。管理者用サイト（8000）と `/api/sync` は今までどおり PC の中だけ。
- 8001 のサーバーにあるのは `POST /line/webhook` と `GET /healthz` だけ（管理者用サイトの画面・API・静的ファイルはない。テストで確かめた）。
- `/line/webhook` は、LINE の署名（`X-Line-Signature` ＝ チャネルシークレットで作った HMAC-SHA256）が合わないものは 401 で断る。比べ方は `hmac.compare_digest`。
- 1MB より大きいものは読まない（413）。
- 登録の番号（6けた）を当てずっぽうで試されないよう、5回まちがえた LINE からは1時間受けつけない（サーバーを起動し直すと数え直しになる）。

### 外部との通信

| どこ | 相手 | いつ |
|---|---|---|
| `app/line_api.py` の `reply()` | `https://api.line.me`（LINE の応答メッセージ） | LINE からメッセージが届いたときだけ。試し運転（`LINE_DRY_RUN=1`）では送らない |
| `scripts/fake_line.py` | この PC の LINE の入口（初期値 `http://127.0.0.1:8001`） | 実行したとき |

- こちらから送るプッシュメッセージは使わない（管理者向けの通知をやめたので、`api.line.me/v2/bot/message/push` への通信はなくなった）。
- LINE のプロフィール（名前・写真）は取りにいかない。

### データを消す・変える処理

| どこ | 何が消える／変わるか | 守り |
|---|---|---|
| LINE で「解除」と送る | その LINE アカウントのつながり | 本人の操作 |
| LINE でブロックされた（unfollow） | その LINE アカウントのつながり | もう返事を送れないため。歩数・ガチャの記録は残る |
| 個人ページの「解除」 | その LINE アカウントのつながり | 確認ダイアログ。サーバー側でも `confirm=yes` がないと消さない |
| 個人ページの「番号を作り直す」 | 前の登録の番号が使えなくなる（登録ずみの LINE はそのまま） | 確認ダイアログ |
| 利用者の削除 | その人の LINE のつながり・番号・ガチャの記録も消える（`ON DELETE CASCADE`） | 確認ダイアログの文を直した |
| `line_events` | 7日より古いイベント ID（送り直しを見分けるためだけのもの） | 自動 |
| `scripts/seed.py --reset` | 新しい表もふくめて全部（設定は残る） | `yes` と入力したときだけ |
| `app/line_notify.py` | ファイルを削除 | Git に前の版が残っている |

- 前からある DB には、使わなくなった `line_logs` の表と、設定の `line_alert_enabled` の行が残る（害はない。わざわざ消していない）。

### 個人情報

- DB に **LINE のユーザーID**（U で始まる）が入る。これは LINE アカウントを見分ける番号なので、個人情報として扱う。画面では一部だけ出す（`U12…abcd`）。CSV には出さない。
- LINE に送るのはニックネーム・歩数・ポイント・ガチャのメッセージだけ。

### 画像

- 使っていない。前の omamori-bot のリッチメニューは画像が要るので使わず、文字のボタン（クイックリプライ）にした。

## 4. 仮で決めたこと（確認が必要）

| 点 | 仮の決め方 | 確認する相手 |
|---|---|---|
| ポイント | 1,000歩=1pt、目標達成で+2pt、過負荷のしきい値（目標の150%）を超えた分の歩数はポイントにしない、ガチャ1回10pt（設定画面で変えられる） | チーム・施設 |
| ポイントの計算 | 歩数の記録から毎回計算（前の案の「毎日23:55に確定」はやめた）。ルールを変えると過去の分も変わる | チーム |
| ガチャ | 前の案のメッセージ8つ。レア度は 60% / 30% / 10% で決めてから、その中で1つ選ぶ（前の案は1つずつに重みが付いていて、★★★ が実際は約7%だった） | チーム |
| 登録 | 職員が作る6けたの番号。家族も同じ番号で登録できる。1つの LINE は1人の利用者とだけつながる | チーム・施設 |
| 使う人 | 本人と家族。グループのトークには対応しない | 施設 |
