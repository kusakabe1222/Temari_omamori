## 1. 何を変えたか

タブレットから見るには、管理者用サイトを `--host 0.0.0.0`（ほかの機器からもつながる形）で起動する必要がある。
そのままだと、ファイアウォールの設定しだいで、同じネットワーク（大学の Wi-Fi など）のほかの人からも開けてしまう。
そこで、**この PC と、`.env` の `ALLOWED_CLIENTS` に書いた機器（IP アドレスか範囲）だけを通し、ほかは 403 で断る**ようにした。

| ファイル | 新規/変更 | 何をするコードか |
|---|---|---|
| `app/main.py` | 変更 | `client_checker()`: 開いてよい機器か調べる。すべてのリクエストの最初に確かめ、だめなら 403（ログイン画面・静的ファイル・`/api/sync`・`/healthz` もふくむ） |
| `app/config.py` | 変更 | `.env` の `ALLOWED_CLIENTS`（カンマ区切り）を読む。IP アドレスや範囲でないものがあれば起動を止める |
| `tests/test_allowed_clients.py` | 新規 | 開いてよい機器・だめな機器のテスト（6件） |
| `tests/conftest.py` | 変更 | テストの接続（`testclient`）を通すようにした |
| `.env.example`, `README.md`, `docs/起動と動作のしくみ.md` | 変更 | タブレットで見る手順（モバイル ホットスポット・`ALLOWED_CLIENTS`・`--host 0.0.0.0`・ファイアウォール） |

- `ALLOWED_CLIENTS` が空なら、今までどおり、この PC からしか開けない（動きは変わらない）。
- LINE の入口（`app.bot_main`・8001）は変えていない。今までどおり `127.0.0.1` だけで起動する。

## 2. 動かし方

README の「タブレットで管理者用サイトを見る」。要点:

```powershell
# .env に ALLOWED_CLIENTS=192.168.137.0/24 を入れてから
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

タブレット（PC のモバイル ホットスポットにつなぐ）のブラウザで `http://192.168.137.1:8000` を開く。

## 3. 注意が必要な処理

- **ネットワークに出す**: `--host 0.0.0.0` で起動すると、PC のすべてのネットワーク（大学の Wi-Fi もふくむ）で待ち受ける。
  アプリの側で `ALLOWED_CLIENTS` にない機器は 403 にするので、画面やデータは見えない。ただし、サーバーが動いていること自体はわかる。
- **ファイアウォール**: 初めて起動したときに Windows の確認が出る。ホットスポットは「パブリック」扱いのことが多いので、README では「パブリック」も許可する手順にした。
  これは Python 全体を「パブリック」で許可することになる。気になるときは、ポート 8000 だけを許可する規則を作る方法もある（PC の管理者として依頼者が行う。Claude はシステムやセキュリティの設定を変えないので行っていない）。
- **暗号化なし**: 通信は http のまま。ホットスポットのパスワードを知っている人だけがつなげる状態で使う前提。
- **プロキシ**: uvicorn は `127.0.0.1` からの `X-Forwarded-For` を信じる（初期設定）。もしトンネルで 8000 を出してしまっても、本当の相手の IP で判定されるので、`ALLOWED_CLIENTS` になければ 403 になる。
- ファイル削除・外部への通信: なし。
